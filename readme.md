# Mi Proyecto
Este es mi proyecto de Git y Github.
Proyecto realizado para practicar Git y GitHub.
Repositorio creado como ejercicio academico.
## Comandos que use

git init:sirve para crear el repositorio de Git en la carpeta donde estoy trabajando.

git add: lo use para agregar los cambios que queria guardar y dejarlos preparados para el commit.

git commit: sirve para guardar los cambios en el historial del proyecto.

git push: manda los cambios y commits que tengo localmente al repositorio de GitHub.

git status: me muestra como esta el repositorio, por ejemplo si hay archivos modificados o cambios que todavia no se han agregado.

git diff:sirve para ver que cambios hice en los archivos antes de guardarlos.

git log: muestra los commits que se han hecho y el historial del proyecto.

git restore:lo use para deshacer cambios de un archivo cuando todavia no habia hecho el commit.

git restore --staged:sirve para quitar un archivo del staging sin borrar los cambios que tenia.
